# Moonlight 前端/全栈成熟化改造实施记录（2026-11-15）

对应文档：

- `app/src/FRONTEND_UX_REVIEW.md`（UI/UX 专项）
- `app/src/FULL_PROJECT_REVIEW.md`（全栈成熟化）

本轮目标是先解决“看着不舒服、用着别扭”的硬伤，再补齐阅读器深读能力与文献管理闭环，并把能离线验证的部分全部固化成测试。

## 一、已落地内容

### 1. 设计系统与全局组件

- 引入 `lucide-react`（`package.json` 依赖），替换 `◐ ◫ ★ ▾ ⋯ ‹ ›` 等字符图标；统一 `stroke-width: 1.75`、16/18px 线性图标。
- 重写 `styles.css` 的色板为清爽暖白：`--bg #f7f6f2`、`--panel #fff`、`--accent #256353`、`--reader-bg #e4e2dc`，弱化分割线、增强文字对比。
- 全局统一的输入框/下拉/文本域基线样式（圆角 8px、focus ring、禁用态），修复“Windows 95 原生控件”问题。
- 新增浮层原语 `FloatingLayer`：Portal 渲染、按触发元素定位、视口夹取/上下翻转、外部 `pointerdown` 与 `Escape` 关闭，供行菜单、导入菜单、选区工具条、高亮气泡、解析菜单复用。
- 新增 `PaperMenu`（行操作菜单项）、`Inspector`（详情抽屉）、`SettingsModal`（分栏设置）、`TagManager`、`DuplicateFinder`、`IdentifierImport`、`ReaderNav`、`FindBar` 等组件。

### 2. P0 交互/定位硬伤（全部修复）

| 问题 | 处理 |
| --- | --- |
| 阅读器下左侧栏常驻、点击分类“假死” | 阅读时隐藏侧栏，左上角汉堡按钮打开浮动抽屉；点击任意分类/标签自动回到列表并应用筛选 |
| 左下角“任务中心”固定悬浮遮挡侧栏 | 移入 `.sidebar-foot`，与“设置与状态”并排，显示运行中任务数徽标（5s 轮询 `list_jobs`） |
| 表格行 `⋯` 菜单永远出现在表格右上角 | 改为基于按钮 `getBoundingClientRect()` 的 Portal Popover；整行右键也能打开；点击外部/`Esc` 关闭 |
| 编辑弹窗原生控件、`<select multiple>` 误清空 | 双列网格 + 分类/标签多选胶囊；全局表单样式；`Esc`/遮罩关闭 |

### 3. 论文库（Library）

- 三层工具栏合并为单行 Header：标题 + 篇数徽标、搜索（`Ctrl+K` / `/` 聚焦）、排序、`导入 ▾`（本地 PDF / Zotero / DOI·arXiv）、表格/卡片切换、列设置。
- 批量操作改为“仅在勾选后浮现”的浮动胶囊：分类/标签、更新引用量、标记已读/未读、批量翻译、导出 BibTeX/RIS、移到回收站、取消选择。
- 单击行/标题 → 右侧 `Inspector` 详情抽屉（可编辑标题、作者、年份、期刊、DOI、arXiv、速记、摘要、笔记、标签、附件版本、阅读状态，一键打开阅读）；双击行或“阅读”按钮才进入阅读器。
- 阅读状态胶囊可点击循环：未读 → 在读 → 已读，无需打开编辑弹窗。
- 卡片视图同步上述行为，并修复菜单定位。

### 4. 阅读器（Reader）

- 选词后不再强制切到“笔记”Tab；改为选区旁浮动工具条：黄/绿/蓝/红高亮、批注、翻译、AI 解释、引用提问、复制。
- 已有高亮可点击：弹出气泡改色、补充批注、跳转、删除（`.highlight { pointer-events:auto }`）。
- 支持 `Alt` 拖拽框选区域批注（图表/公式），浮动气泡内写备注。
- AI 面板重构为三段式 Chat：顶部快捷动作 + 上下文设置 Popover，中部按时间排序的消息流（Markdown、引用胶囊 `[1] p.4`、复制/存笔记/导出），底部 Sticky 输入区（选区引用条、Enter 发送、Shift+Enter 换行、停止生成）。
- `DocumentParsing` 从常驻工具条收敛为顶部状态胶囊：`✓ 已索引 x/y`，仅当当前页无原生文本层时显示“扫描页 · 一键 OCR”；详细动作在 Popover 内。
- 右侧 AI/笔记面板支持拖拽调宽（280–560px，持久化）与一键收起。
- 阅读器新增：PDF 目录大纲 / 页面缩略图侧栏（`doc.getOutline()` + canvas 缩略图）、`Ctrl/Cmd+F` 文内查找（计数、上下跳转、命中框高亮）、PDF 内链与外链（自绘 `linkLayer`，避免引入整份 `pdfviewer.css`）、阅读位置历史栈（`Alt+←/→`）、缩放到“适应页宽/适应整页”与预设档位、`Ctrl+滚轮` 缩放、`J/K/PageUp/PageDown/Home/End/+/-` 快捷键。
- 多译文版本：顶部可切换历史译文版本，批注按所选译文版本过滤，重新翻译后旧译文批注仍可回看。

### 5. 设置与文献管理闭环

- 设置弹窗改为 760×560 左右分栏：通用与论文库 / 翻译引擎 / AI 阅读助手 / 云同步 / 备份与恢复。
- 翻译设置新增 `测试 API 连接`、`检查 BabelDOC` 诊断按钮（`translation_probe` / `check_babeldoc`）；保存后通过 `reload_gateway` 热更新网关，`pending_restart` 为 false 时无需重启即生效；失败会明确提示并保留重启兜底。
- 目录管理支持删除（子目录提升、论文不删）、合并；标签管理支持重命名、改色、删除；批量归类支持“移除归类”（`bulk_unassign`）。
- Inspector/编辑器新增“通过 DOI / arXiv 自动补全”按钮（Crossref → arXiv，只在字段为空时补齐，可强制覆盖）。
- 导入支持拖拽 PDF（Electron `webUtils.getPathForFile` + 批量导入）与“通过 DOI / arXiv 导入”（自动解析元数据、下载开放 PDF、入库并补全字段）。
- 设置→通用新增“查找重复论文”（按 DOI / arXiv（去 vN）/ 归一化标题分组）。

### 6. 核心层（Rust）与主进程

- `search.rs`：移除“rowid 拉回 Rust → `json_each` 回传”；匹配集合物化到连接级临时表后与 `papers` 在 SQLite 内关联、排序、分页；新增汉字 bigram FTS（`papers_bigram` / `blocks_bigram`）与触发器维护，解决 2 字中文（蒸馏/量化/微调）与 2 字母缩写（RL/LM）检索。
- `ai.rs`：中英学术术语扩展（显存→memory/vram 等 25+ 组）、译文块联动检索并映射回原文页、词频/BM25 风格排序；纯中文提问可命中英文 memory/bottleneck 段落，不再退化为按页抽样。
- `organization.rs`：`folder_delete` / `folder_move` / `folder_merge` / `tag_rename` / `tag_set_color` / `tag_delete` / `bulk_unassign` / `list_duplicates`（事务化，不删论文）。
- `pdfmeta.rs` / `citations.rs` / `library.rs`：`refresh_metadata`（arXiv → Crossref，字段为空才补、可 force；网络错误可读、不 panic；测试全部注入不联网）。
- `engine.rs` / `library.rs`：`reload_gateway`（保存后热重建网关）、`translation_probe`（最小 chat 探针，返回 `{ok,latency_ms,model}` 或 401/404/超时等可读错误）、`check_babeldoc`（显式路径 → 保存路径 → 内置运行时 → `.venv` → PATH，返回 path/version）。Windows 便携包现已内置 BabelDOC 运行时（CPython 3.13 + 固定依赖闭包），详见 [BABELDOC_BUNDLING.md](BABELDOC_BUNDLING.md)。
- `electron/import-identifier.cjs`：arXiv ID/URL、DOI/doi.org 解析、Atom/Crossref 元数据解析、PDF 下载（≤80MB、校验 `%PDF`）、入库与元数据补全；主进程 IPC `dialog:import-identifier` + preload `importIdentifier`。
- 主进程新增 `dialog:import-paths` / preload `importPaths` / `getPathForFile`，支持拖拽导入。
- 编辑器/详情抽屉提供“通过 DOI / arXiv 自动补全”按钮（手动触发，避免导入后台写库与用户编辑产生 updated_at 竞态）。

## 二、验证

```bash
# 前端类型检查 + 单元测试 + 主进程/Node 测试
cd app
PATH=/home/bynshard/.local/node22/bin:$PATH npx tsc --noEmit
PATH=/home/bynshard/.local/node22/bin:$PATH npm test        # 10 files / 36 tests + 46 node tests
PATH=/home/bynshard/.local/node22/bin:$PATH npm run build

# Rust 核心
cd core
PATH=$HOME/.cargo/bin:$PATH cargo test --offline            # 48 passed / 4 ignored
```

视觉回归：`app/e2e/visual-check.mjs` 用 Playwright 注入完整 `window.moonlight` mock（含真实 PDF 字节），覆盖论文库、行菜单、编辑器、卡片、详情抽屉、批量栏、设置各 Tab、标签/目录管理、DOI/arXiv 导入、大纲、缩略图、文内查找、选区工具条。运行：

```bash
cd app
PATH=/home/bynshard/.local/node22/bin:$PATH node e2e/visual-check.mjs
```

（无 CJK 字体的 headless 环境需通过 `FONTCONFIG_FILE` 指向包含中文的 fonts.conf，否则界面中文会显示为方框。）
