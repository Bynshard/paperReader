# 目录、标签、速记和引用量（本地已验收，发布待验证）

本轮改动尚未提交、推送或发布，现有 v0.1.0 包不包含新入口。

## 操作入口

- 左侧“目录 → 新建 / 管理”：新建顶层或子目录，也可选择已有目录修改名称或上级。真实父子关系保存在 SQLite，最多 32 层，防止循环、重复同级名称和不存在的父目录。
- 点击父目录会包含后代目录的论文；一篇论文允许同时出现在多个目录，文件不会因为归类而复制或移动。
- “全部论文”逐篇点击“分类 / 标签”，或勾选当前页多篇后批量归类、打标签。批量操作追加关联，保留旧目录和标签；移除关联可在单篇“编辑资料”中处理。不存在/已删除的论文使整个批次回滚。
- 逐篇点击“速记”可编辑最多 300 字的一句话总结，不打开 PDF；速记直接显示在列表，也能在编辑资料中维护。它独立于摘要和长笔记，支持全文搜索，保存时检查资料版本以避免覆盖其他修改。
- 点击标签可筛选；搜索框同时匹配元数据、速记、标签和正文。

## 引用量

单篇“刷新引用量”主动联网更新；“更新所选引用量”逐篇执行，近期 7 天的缓存直接复用，可停止后续更新。不会在滚动、排序、导入或打开论文时自动联网，也不会自动向服务上传 PDF、笔记、速记或整库。

DOI 使用 Crossref `is-referenced-by-count`；Crossref 未覆盖或不可用时尝试 Semantic Scholar 的相同 DOI。只有 arXiv ID 时使用 Semantic Scholar 的 `citationCount`。查询核验返回的精确标识，不按近似标题猜测；缺失标识时提示编辑资料。界面显示来源，悬停可见更新时间；不同来源统计口径不同。

未知、未收录、接口限流或网络失败均不会被写成 0，已有缓存保留。真正返回的 0 正常展示。改动 DOI/arXiv ID 会使旧统计失效；查询期间若标识发生变化，不会写入旧论文的查询结果。公共接口可能限流，程序串行请求并限制频率，不会自动重试轰炸接口。

“论文排序 → 引用量（从高到低）”在 SQLite 中排序后分页；未知排在已知数据之后。目录树和论文列表均复用 TanStack 虚拟渲染。速记增加独立 trigram 全文索引，并保留索引化的父目录查询与引用量排序。

## Zotero、同步和备份

Zotero 数据库迁移保存真实父子目录，保留稳定目录 ID 和条目关联；再次迁移时可把此前平铺的 Zotero 路径分类升级为真实目录。导入还把逐篇遍历所有目录改为按条目关联查找。

目录层级、速记与引用量随 SQLite 备份保存，并进入现有元数据同步协议。目录的多条协同移动在一个事务中应用，合并后检查循环；同步两端都需要升级到具有这些字段的版本。引用量只是最近一次查询的缓存，不代表实时统计。

## Zotero Style 式列表（本地已验收，发布待验证）

参考 [Zotero Style / Ethereal Style](https://github.com/MuiseDestiny/zotero-style) 的增强列表、标签、阅读状态与视图配置。本软件默认使用紧凑表格，另保留卡片视图；表格可展示标题/作者、年份、引用量、彩色标签、速记、目录、阅读状态。未读标题加粗，标签可筛选，速记可在单元格直接编辑。

复用 TanStack Table 的列显示与列宽调整，配合 TanStack Virtual，仅为可见行建立表格行模型。标题、年份和引用量表头调用现有数据库排序；不会对整库做 JavaScript 排序。支持研究概览、阅读与速记、引用量与标签布局，个人列宽/显示列/展示方式保存在当前应用配置的 localStorage，不作为论文库数据同步。

本轮并未复制整个 Zotero Style 插件，也没有实现阅读时间热力图、逐页批注密度、期刊分区或多星评级。新增列表已通过真实桌面列宽、显示列、速记编辑、重启保留验证，以及万篇库浏览器测试；仅挂载 15 行。真实 Windows 发布包与长期使用仍待验收。本轮未提交或推送。
