# 2026-11-01 万篇库验收结果

本轮完成可复现验收和瓶颈修复；**尚未达到成熟发行版标准**。高命中率正文搜索仍超过 200 ms P95 目标，保留失败门槛。

## 数据与环境

Linux / AMD Ryzen 7 6800H / 16 逻辑 CPU。10,000 份独立 PDF 经实际 Rust 导入，其中 9,998 份为生成的 4–12 页文档、2 份为实际论文。40 万余正文块、10,000 个批注、10,000 个分类关系、20,000 个标签关系。不能当作一万篇自然论文语料。

生成 PDF 用时约 260.8 秒；逐份协议导入总计 468.2 秒（约 7.8 分钟），每份 P95 70.78 ms。这是优化前完整导入，修复后复用同一库测查询和竞争负载，没有声称重新完整导入一万份。

## 仍需解决

高命中率正文搜索约 0.46 秒 P95；两个读取任务同时被长查询占满时新列表仍会排队。全文精确总数与匹配集计算仍需进一步优化，当前不通过 200ms 发布门槛。

PDF 仍整文件读取/传输，尚未接入按需范围读取；浏览器压力样本有限，不能代表超大扫描书和所有复杂 PDF。完整 Electron IPC、安装包、多平台和长期峰值内存、自然论文语料及模型服务仍需验收。
